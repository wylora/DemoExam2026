# Демонстрационный экзамен: конференции

Решение демоэкзамена из двух частей: база данных и настольное приложение.

## Часть 1. База данных (`Часть1_БД`)

- `DEMO2023_script.sql` — скрипт создания и заполнения БД **DEMO2023** (Microsoft SQL Server)
- `DEMO2023_проверка.sql` — проверочные запросы
- `ERD_01.pdf` / `ERD_01.docx` — ER-диаграмма
- `DATA.xlsx` — исходные данные для импорта

## Часть 2. Приложение (`Часть2_Приложение/ConferenceApp`)

WPF-приложение на C# (.NET Framework 4.8, Entity Framework 6):

- авторизация с CAPTCHA
- окна для ролей: участник, модератор, жюри, организатор
- список мероприятий
- регистрация жюри и модераторов с проверкой пароля

### Запуск

1. Выполните `DEMO2023_script.sql` на `(localdb)\MSSQLLocalDB` (или поменяйте строку подключения в `App.config`).
2. Откройте `ConferenceApp.sln` в Visual Studio, восстановите NuGet-пакеты и запустите.
